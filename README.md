
# Homework 2 – Unity Mini-Map Demo

**Course:** Computer Game Development

**Submitted by:** Ahmad Bsher

## Part A – Unity Project

A 2D game developed using Unity 6000.3.25f1.

### Features
- Player movement using arrow keys or WASD.
- Mini-map displayed in the top-right corner.
- Collectible stars and obstacles.
- Camera adaptation using orthographicSize.
- Unity Input System and InputAction.
